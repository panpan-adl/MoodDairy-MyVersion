# 心语个人 Agent 第一版

当前实现在 MoodDairy-MyVersion/MoodDairy，启动后默认进入“今天”。页面沿用应用的薄荷绿与淡黄绿渐变、白色圆角卡片，上方展示今日概览，下方分为“记录与计划”“今日任务”“晚间复盘”三个页签。

## 使用流程

1. 在“记录与计划”页签输入目标或想法，选择精力与当天可安排的时间。
2. 点击“生成今日计划”，预览工作、学习、生活任务。可以编辑名称、分类、预计时长和下一步，也可以移除或手动添加任务。
3. 点击“确认加入今天”。任务与原始记录一起保存；记录作为私密日记保存。
4. 在“今日任务”页签按工作、学习、生活筛选，并标记完成、编辑任务、进入已有专注计时器，或延期到明天。
5. 在“晚间复盘”页签补充当天感受，生成复盘。修改草稿后，点击“保存为私密日记”。
6. 没有任务时，可以直接“只保存记录到日记”。AI 不可用时可以“手动安排”。

底部导航提供今天、助手、记录、发现、我的。原有日记、日历、发现及账户功能仍可访问。

## 实现与配置

- 安卓端 TodayScreen / TodayViewModel 负责今日中心。草稿使用 EncryptedSharedPreferences，按账户和日期分别保存。
- 后端 personal_agent 路由负责规划、确认、任务修改、独立记录和复盘。
- 复用现有 todos 与 diaries 表，不需要数据库迁移。任务分类显示为【工作】、【学习】、【生活】，预计时长和下一步以可读文字保存在待办备注中，原日历也能显示。
- 使用现有 ARK_API_KEY、ARK_MODEL_NAME、ARK_BASE_URL。凭证缺失或服务不可用时返回明确错误，不生成虚假的 AI 结果。
- 规划参考用户最近 7 天最多 12 篇日记和当天任务；这属于近期背景记忆。长期目标管理、日历同步、外部服务执行及自动提醒未包含在这一版。
- 模型生成计划的时间预算扣除已有未完成任务；低精力时最多安排 90 分钟。用户可在预览中主动修改并确认超出预算的计划。
- 写入使用登录身份；读取和修改任务均限定账户。计划与记录同一事务提交；写入请求使用 UUID 和 PostgreSQL 事务锁处理重试与并发。
- 日记沿用现有字段加密，发给模型的背景先经过项目已有隐私脱敏。
- 首页将重要任务定义为当前排序中的前三项未完成任务；预计分钟数用于时间预算，不是已预约的日历时段。

## 本地运行

使用仓库根目录 start_chat_backend.ps1 启动当前版本后端。后端新增接口需要重新启动服务。
安卓应用需要可访问该后端；本机模拟器沿用项目现有端口转发和 local.properties 配置。

## 验证

- 后端：在 backend 目录运行 python -m pytest tests/test_personal_agent.py tests/test_chat_router.py -q。
- 安卓：配置本机 ANDROID_HOME 后，运行 gradlew.bat :app:assembleDebug :app:testDebugUnitTest --offline。
- 真实模型：已使用虚构记录验证工作、学习、生活任务 JSON 和区分完成/未完成状态的复盘 JSON。
- 模拟器：新版已安装，并验证今日中心及导航显示。

后端回归测试使用独立 SQLite 数据库执行真实 ORM 查询；PostgreSQL 专用事务锁在这些测试中跳过，因此不代表生产多进程并发压力测试。
