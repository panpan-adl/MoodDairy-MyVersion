# 时光信箱与情绪空间 · 1.4.3

两个功能复用原账号、云端文字模型和日记，不需要电脑配对，也不会扫描电脑文件或自动读取未选择的日记。

1.4.3 连接修复：MemoryStore 原先独立创建默认 OkHttp 连接，遗漏主工程针对 adb reverse 的 `Connection: close` 设置，且默认读取超时仅10秒。新连接统一关闭长连接复用，并设置15秒连接、90秒读取/写入与总时限；视频播放器同步配置。没有添加业务层自动重放写入操作。网络中断或超时显示中文恢复提示，本地草稿保留。当前 USB 开发方式仍需电脑后台正常运行；启动入口会恢复后台并刷新8000端口转发。

1.4.2 视频样式：改为暖白信纸、优先楷体的大字号正文、段落留白与淡横线。开头停留3秒，正文连续向上滚动，结尾停留5秒；保留原声与可选配乐，随信照片以相纸形式跟在正文后。采用已确认的字幕段落；没有字幕时使用正文和所选日记，避免原来的每100字切换一张画面。中文标点不单独落行，正文不静默截断；若三分钟内无法保持可读速度，会提示精简内容或减少照片。预览窗口扩大以便阅读。

未封存、可预览的视频可点击“重新生成信纸滚动版”，正文、素材和开启日期不变；封存或已开启的原信禁止重做。字体可由 `MEMORY_LETTER_FONT` 指定，缺省使用系统楷体或已有中文字体。

1.4.1 修复：数据库中不存在、已停用或与旧令牌身份不匹配的账号，会在所有新功能接口进入前被拒绝并要求重新登录，不再尝试创建空间而触发外键错误。手机只清理失效会话，保留各账号的本地加密草稿；验收脚本也不再恢复已失效的旧账号会话。本次39项后端回归、Android构建与单元测试通过，另用2项原生测试验证了正常视频生成和失效账号的鉴权错误及草稿保留。

## 使用入口

- 发现 → 时光信箱 / 情绪空间。
- 助手上方 → 制作未来视频信 / 布置情绪空间。
- 已保存日记顶部 → 写给未来的自己 / 放进我的空间。

## 时光信箱

1. 写标题和正文，选择未来开启日期（默认北京时间当天零点）。
2. 可选择最近100篇中的最多5篇日记，以及日记里的照片、录音；也可以直接选手机文件或录原声。
3. 先保存到账号。素材会制作独立加密副本，原日记以后修改或删除不改变这封信。无法确认原始归属的历史媒体会要求重新选择本机文件。
4. 可以由云端 AI 整理字幕，也可以直接手动写。字幕按空行分段，支持修改顺序和内容；生成失败不会伪造结果。
5. 生成视频后预览、导出或确认封存。最多12张照片、1段最长3分钟录音；竖屏720×1280 MP4，字幕、轻微动态、淡入淡出和可选配乐。长文字需先整理到2400字以内。
6. 封存后不能修改日期或查看正文、素材、视频。由服务端校验时间，到期后仍需主动点击开启。修改手机时间不会解锁。
7. 开启原信后可制作一份回应。双时间线依次标注“当时的我／现在的我”；每部分超过90秒时，合成版会保留全部内容并适度加速，让总时长不超过3分钟。独立原信保持原速、不被覆盖。

封存前用户自行录屏和导出的副本无法收回；这项规则控制 App 中的后续访问，不是防拷贝 DRM。视频播放与下载都经过账号和状态校验，支持 Range，不返回公开文件地址，响应禁止缓存。

手机可以保存多份加密草稿；未上传素材加密保存在应用私有、不可备份目录，重开后可继续，不同账号隔离。移除手机草稿不删除账号里的信。到期通知不展示私人正文，系统每约6小时检查一次；权限、省电与网络可能延迟通知，进入信箱会重新检查。

## 情绪空间

每个账号一个二维房间，内置温暖书房、安静卧室、自然小屋三种主题和12个位置。

- 日记/复盘 → 本子或纪念物；照片 → 相框；录音 → 录音机；视频信 → 信箱。
- 点击物品可查看来源；日记显示最新内容，删除后显示来源已删除。移除物品不删除原记录。
- 先选1至5篇日记，AI 提出可修改的物品、说明和空位置。点击确认才写入；不会自动覆盖物品。
- 修改某个物品时可换位置或来源，目标位置必须空闲；要替换占用位置，请从该位置的物品进入“修改位置或替换”。
- 切换主题保留内容；封存的信只显示通用信封和日期，不暴露正文和敏感缩略图；到期出现提示，不自动播放。
- 房间下方提供物品列表，便于查找与辅助阅读。空间不会根据情绪变坏，也不以使用次数评价心理健康。

## 部署与数据

- 新增5张独立表，启动时只为新表执行可重复的创建，不改原日记与任务表；数据库账号需具有相应建表权限。
- 私有文字使用现有字段加密。素材副本和成品加密存储在 `backend/data/memory-private`，不能放入公开 uploads，也不进入 Git。
- API 与渲染进程分开运行。本机 `start_chat_backend.ps1` 会同时启动两者，渲染进程退出后自动重启。其他部署环境需要单独托管 `python scripts/memory_worker.py`。
- 任务记录在数据库中。渲染持有事务锁，进程中断后任务可重新领取；成功写入加密成品后才标记完成。处理中不允许编辑或删除，以免覆盖素材。
- FFmpeg 使用已安装的 imageio-ffmpeg。Windows 默认查找微软雅黑/黑体；Linux需配置中文字体文件 `MEMORY_CJK_FONT`，例如 Noto Sans CJK。缺少字体会明确失败。
- 可设置 `MEMORY_PRIVATE_DIR` 到私有持久磁盘。备份时需同时备份数据库、此目录和现有加密密钥，单独复制数据库不能恢复视频。
- 生成与同步需要后端和网络。文字整理会把用户明确选中的文字交给现有云端模型；视频合成本身使用 FFmpeg，不调用付费生成视频接口。

## 验证入口

- 后端回归：`tests/test_memory_skills.py`，包含封存、到期边界、归属、素材重试、版本冲突、来源删除及主题切换。
- 真实完整流程：`scripts/smoke_memory_skills.py`，使用临时账号和虚构素材，完成后清理测试数据。
- 中断恢复：`scripts/smoke_memory_recovery.py`，只中断临时测试任务；发现其他排队任务时跳过破坏性验证。需安装维护工具 psutil。
- Android 设备测试：`MemorySkillsInstrumentedTest` 验证三种房间点击、草稿加密与账号隔离；原键盘测试保留。
- 本次验收：37项后端回归通过；Android构建与单元测试通过；5项空间/草稿/键盘设备测试及1项临时账号原生完整操作测试通过。真实云端字幕、私有MP4、双时间线、封存保护、空间联动及进程中断自动恢复均已验证。
- 原生完整操作测试由 `scripts/smoke_memory_android.py` 创建临时账号、运行设备测试并清理数据。截图均为虚构内容：[空间界面](screenshots/memory-native-screen-qa.png)。

正式发布前仍需在真实手机验证麦克风权限、不同相册文件格式、通知与电池管理差异。当前开发安装包使用 USB 转发访问电脑上的后端；脱离开发电脑使用需配置正式后端地址。
