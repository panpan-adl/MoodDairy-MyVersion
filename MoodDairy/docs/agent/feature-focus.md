# 心语 1.4.4 功能与入口

心语以情绪记录为基础，以小嘉然陪伴为核心，围绕“记录感受 → 交流 → 选择支持方式 → 回顾并保存经历”组织功能。

- 今天：保留工作、学习、生活规划，精力和时间预算、任务拆解、完成情况、晚间复盘；取消番茄钟入口。“查看以往任务”可查看旧待办，标记完成或安排到今天。
- 助手：日记上下文、Live2D、表情授权与识别保留；数字人合并不在本次范围内。
- 测试：发现页不再展示测试中心。向小嘉然说“我想测一下 MBTI”获得对应卡片，点击进入；未指定种类时提供现有六种测试选择。聊天卡片附有测试历史入口。
- 心理内容查找：明确请求心理书籍、纪录片、心理科普、放松资源时生成费用确认卡片。确认前不请求 TikHub；沿用原有平台与计费规则，默认 B站和知乎，其他平台必须由用户点名。普通倾诉不触发付费搜索。结果标注来源与相关内容类型，不保证完整作品。
- 搜索账户：我的 → 搜索服务设置，提供密钥绑定、更换、余额刷新和官方充值跳转。聊天只在无密钥、密钥失效或余额不足时提供设置引导。
- 放松一下：聊天卡片进入，分为音乐和白噪音，不自动播放。音乐沿用现有网易云搜索，打开外部歌曲页，播放/暂停由网易云或浏览器控制；本地白噪音支持混音、音量和跨页面停止。
- 发现：时光信箱、情绪空间、成长画像、高光时刻、小确幸。成长画像不再依附测试板块。
- 创作：原有日记→图片→视频、草图增强、LoRA 和独立创作流程保留。

个人视频导入/搜索的界面、专用接口、服务及工具已移除，成就、积分、商店和兑换代码已移除。独立待办与番茄钟入口停用；规划继续复用 todos。旧白噪音动作转入放松页，旧待办页面链接转入今天。旧接口名 `open_test_hub` 保留用于兼容，但返回 `offer_tests`，客户端展示聊天卡片；点击才发送页面导航动作。

新增 `GET /api/agent/tasks/history`：按登录账户返回今天以前的任务，日期以北京时间计算；任务修改继续使用原有受账户限制的接口。不改动旧任务日期，不删除数据库表、历史任务、积分本地数据或个人视频旧索引文件。日记、画作、信箱和空间结构保持不变。

验收重点：搜索确认/取消及失败反馈；指定/未指定测试卡片与历史持久化；旧任务访问与账户隔离；放松页无自动播放；日记绘画视频及记忆功能回归。旧设计文档描述历史功能，当前入口以本文和统一工程为准。
