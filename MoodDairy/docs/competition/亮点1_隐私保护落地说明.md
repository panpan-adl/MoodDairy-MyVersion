# 亮点 1：多模态隐私保护 — 落地说明

> 对应参赛规划中的「端云协同私域情感认知网络」安全能力，**不含 HTTPS 强制**（按当前阶段跳过）。

## 一、已落地能力

| 层级 | 能力 | 实现位置 |
|------|------|----------|
| 认证 | bcrypt 密码哈希 + 旧明文兼容升级 | `backend/app/security/password.py`、`user_service.py` |
| 认证 | JWT 签发/校验（7 天默认过期） | `backend/app/security/jwt_auth.py` |
| 认证 | 全局 JWT 中间件 + 路由级 `EffectiveUserId` | `middleware.py`、`deps.py`、各 router |
| 端侧 | EncryptedSharedPreferences 存会话/JWT | `SecurePreferences.kt`、`SessionManager.kt` |
| 端侧 | OkHttp `Authorization: Bearer` 拦截器 | `AuthInterceptor.kt`、`NetworkModule.kt` |
| 存储 | 日记 title/content Fernet 字段加密 | `field_crypto.py`、`diary_service.py` |
| 出站 | LLM 调用前 PII 脱敏 | `pii.py`、`chat.py` |
| 媒体 | OSS presigned 临时 URL | `media_access.py`、`oss_service.py`、日记/媒体响应 |
| 审计 | `security_audit_logs` 表 + 登录/注册/资料/日记 CRUD | `audit.py`、`004_security_audit_logs.sql` |
| 日志 | 敏感信息日志过滤 | `log_filter.py`、`main.py` |

## 二、部署检查清单

1. **安装依赖**：`pip install -r backend/requirements.txt`
2. **执行迁移**：在 PostgreSQL 运行 `backend/migrations/004_security_audit_logs.sql`
3. **配置 `.env`**（参考 `backend/.env.example`）：
   - `JWT_SECRET` — 必填，生产用随机长字符串
   - `FIELD_ENCRYPTION_KEY` — 可选；不填则字段加密关闭，新日记仍以明文存库
   - `OSS_USE_PRESIGNED_URLS=1` — OSS 私有桶时启用
4. **Android**：升级后旧 `SharedPreferences` 会话不兼容，需重新登录

## 三、API 行为变化

- 除 `/api/users/login|register`、`/health`、`/docs`、本地 `/media/` 静态资源外，**所有 API 需携带 JWT**。
- 请求中 `user_id` 若与 token 不一致，返回 **403**（防 IDOR）。
- 登录/注册响应新增 `access_token`；Android 自动持久化并在后续请求附加 Bearer。

## 四、答辩演示建议

1. 抓包对比：无 token → 401；错误 user_id → 403
2. 数据库：新日记 `content` 以 `enc:v1:` 前缀存储（配置密钥后）
3. 聊天请求：日志/网关层可见 PII 已替换为 `[PHONE]` 等占位符
4. OSS：媒体 URL 为带过期时间的 presigned 链接
5. `security_audit_logs`：展示登录、日记创建/更新/删除记录

## 五、已知限制

- 历史明文日记/密码在首次登录或读取时逐步迁移，非一次性批量加密
- HTTPS 强制未启用（竞赛演示环境可按 HTTP + adb reverse）
- 绘图/视频等火山方舟能力依赖账户余额，与安全改造无关
