### 1.2 赛项划分

竞赛分为 **创意（A）** 与 **攻关（B）** 两大系列：

| 赛项 | 说明 | 心语是否适合 |
|------|------|-------------|
| **普通 A** | 主题、技术、平台自选，须关联网络技术分支 | ✅ **推荐** |
| A-ST | 网络空间与信息安全专项 | ❌ 非安全类产品 |
| A-ICV | 车联网与交通智能网联专项 | ❌ 与产品无关 |
| B-EP1 | 未来网络 · 智能体互联网创新攻关 | ❌ 企业定制约束大、重构成本高 |

### 1.3 为何选择普通 A

心语是 **Android 端云协同的智能日记 / 心理健康辅助应用**，核心能力包括：

- AI Agent 对话与工具调用
- 私域 RAG 向量检索
- 情绪结构化提取与心理量表
- 云计算后端 + OSS 媒体存储
- 异构算力（云端 LLM / 本地 Stable Diffusion LoRA）

这些能力可自然映射到规程要求的 **网络智能、云计算、网络数据分析、算力网络、边缘计算** 等分支，无需强行切入网络安全或车联网场景。

> **注意**：现有部分设计文档标注为「A-ST」，与产品实际定位不符，参赛材料应统一改为 **普通 A**。

## 五、三大创新亮点

### 亮点 1：私域情感语义检索网络

**痛点**：通用大模型无法长期记住用户私人日记；全量上云又有隐私顾虑。

**方案**：

- 按用户隔离的 FAISS 向量索引（`DiaryFAISSStore`）
- 向量检索 + 关键词提取 **双路召回**（`RAGRetriever`）
- 聊天 Agent 自动注入 RAG 上下文（`chat.py` → `_retrieve_knowledge`）

**竞赛增强（待实现）**：

- [ ] 正式启用 RAG，配置 `RAG_ENABLE=1`
- [ ] 增加 **情感感知重排序**（结合 `primary_emotion`、日期权重）
- [ ] 输出量化指标：Recall@K、P95 检索延迟、上下文命中率

**创新表述**：构建面向个人私域数据的 **「情感语义检索网络」**，而非通用搜索引擎。

---

### 亮点 2：端云协同 Agent 安全执行网络

**痛点**：AI 助手若可未经确认修改用户数据，存在误操作与信任风险。

**方案**（已实现）：

- 工具分级：`read_only` / `operation` / `client_action`
- 写操作需用户确认后再执行（`PlanStore` + 确认流）
- SSE 流式多轮 Agent 交互

**竞赛增强（待实现）**：

- [ ] 绘制 Agent 执行状态机 + 端云交互时序图
- [ ] 统计工具调用成功率、用户确认率、平均响应时延
- [ ] 答辩对比「无确认 Agent」与「安全网关模式」

**创新表述**：在网络智能架构中引入 **「Agent 执行控制面」**，实现端云协同的安全 AI 操作。

---

### 亮点 3：情感数据网络分析与关注提示

**痛点**：用户持续记录日记，但难以从碎片化文字中看出情绪趋势与变化规律。

**方案**（部分已有，Dashboard 待建设）：

- 利用 `diary_summaries` 表的 `emotion_score`、`emotion_distribution`
- 结合 PHQ-9 / SDS 心理量表历史
- 生成情绪曲线、周期报告、波动关注提示（**非医疗诊断**）

**竞赛增强（待实现）**：

- [ ] 新增 **情感分析看板**（App 内页或 Web 管理端）
- [ ] 可选：关联天气、地点字段做关联分析
- [ ] 对接「青少年 / 大学生心理健康」社会热点叙事

**创新表述**：将私人日记数据转化为 **可分析、可感知的情感网络数据流**，体现网络数据分析应用价值。

## 六、算力网络加分项（可选）

### 6.1 异构算力调度叙事

| 算力节点 | 能力 | 触发条件 |
|----------|------|----------|
| 云端 Ark API | LLM 对话、Embedding、Seedream 文生图、图生视频 | 网络良好、账户有余额 |
| 本地 / 服务器 SD | LoRA 个性化文生图 | 云端不可用或需隐私保护 |
| Celery Worker | 日记结构化提取、向量化 | 异步后台，削峰填谷 |

### 6.2 降级策略（可演示）

当云端 API 返回 `403 AccountOverdueError` 或网络超时时：

1. 聊天功能提示降级，保留本地只读功能
2. 绘图切换至本地 Stable Diffusion 推理
3. 提取任务在 Celery 队列中重试

此策略可作为 **「算力网络 + 网络韧性」** 的答辩亮点。

## 十、答辩常见问题预案

### Q1：你们的作品和网络技术有什么关系？

**答**：心语不是单纯的 AI 应用，而是构建了 **端云协同的私域情感认知网络**：移动端通过 REST/SSE 与云端通信；云端部署 RAG 向量检索网络实现语义搜索；Agent 执行网络实现安全的 AI 操作编排；情感数据分析层对日记情绪数据进行网络级聚合与趋势分析。关联分支包括 **网络智能、云计算、网络数据分析**。

### Q2：与市面日记 App / ChatGPT 有什么区别？

**答**：三点差异 —— (1) **私域 RAG**：检索用户自己的历史日记而非通用知识；(2) **安全 Agent**：写操作需用户确认；(3) **情感数据分析**：从日记中自动提取结构化情绪并生成趋势报告，而非纯聊天。

### Q3：隐私如何保护？

**答**：敏感日记数据存储在用户专属数据库记录中；向量索引按用户隔离；Agent 写操作需端侧用户确认；Session 本地缓存；可选端侧 Live2D 交互减少不必要云端传输。

### Q4：RAG 检索准确率如何？

**答**：（需实测后填写）采用向量 + 关键词双路召回，在 N 条测试 query 上 Recall@5 达到 X%，P95 检索延迟 Y ms。
